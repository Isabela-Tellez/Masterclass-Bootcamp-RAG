# 🧙‍♂️ Guía Pedagógica para Docentes — Masterclass RAG (Somos F5)

Esta guía detalla la metodología pedagógica para una **sesión exprés (45–50 min)** centrada principalmente en la **App Frontend interactiva** y el **Quiz**, utilizando los notebooks únicamente como material complementario.

## ⏱️ Estructura y Tiempos de la Sesión (45–50 Minutos)

| Bloque | Contenido | Recurso Principal | Tiempo |
| :--- | :--- | :--- | :--- |
| **01. Intro & Diapositivas** | Conceptos clave de RAG y Embeddings | Slides (`/src/slides`) | 10 min |
| **02. Demo Interactiva** | Ingesta, Chunking y Vector Store en tiempo real | Componente `RagDemo.jsx` | 20 min |
| **03. Quiz Interactivo** | Evaluación rápida y fijación de conocimientos | Componente `Quiz.jsx` | 10 min |
| **04. Cierre & Recursos** | Despedida y entrega de Jupyter Notebooks autónomos | `docs/` | 5 min |

## 📂 Recursos Complementarios (Trabajo Autónomo)

Los siguientes archivos quedan a disposición de los estudiantes para profundizar tras la clase:

* **`teoria_rag.pdf`**: Documento de lectura de apoyo teórica.
* **`masterclass_rag_estudiantes_TODO.ipynb`**: Cuaderno práctico para que ejecuten el pipeline RAG en Python a su propio ritmo.
* **`masterclass_rag_docente_solucion.ipynb` / `masterclass_rag_solucion_reto_DOCENTE.ipynb`**: Solucionarios de referencia para dudas técnicas avanzadas.
